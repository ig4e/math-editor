# Project Status: Abandoned

**Date abandoned:** 2026-05-14

This project — **Math Notebook** — is no longer maintained. The
GitHub repository has been archived and is read-only.

## What this means

- No further commits, releases, or version bumps will be made.
- No bug fixes, including for security issues in dependencies.
- Issues and pull requests will not be reviewed, triaged, or merged.
- No support is provided through any channel.

## Using the code

The source remains available under its existing license for reference,
study, and forking. If you want to continue development, please fork
the repository — you are free to take it in any direction.

## Dependencies

The third-party libraries this project depends on (Excalidraw,
MathLive, Cortex Compute Engine, JSXGraph, three.js, Pyodide, the
Vercel AI SDK, and others — see [`NOTICE`](./NOTICE)) continue to be
maintained by their own communities. If you fork, you will likely
need to refresh those dependencies before doing further work.
